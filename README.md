# kf-slack-application 🏎️

学生フォーミュラチーム向けの、会計管理およびドキュメント検索（RAG）を統合したSlack Botです。
SlackをUIとしたことにより、スマートフォン等からでも簡単に様々な機能を利用できます。

## プロジェクトの目的
学生フォーミュラの活動では大会成績を出すために必要な車両設計・製作以外に様々な事務作業や組織運営面の課題等が存在します。
メンバーは設計や製作に集中したいにもかかわらず、ほかのことに追われて、それがかなわないことがあります。
このプロジェクト開発は2022年5月~チームに在籍してきた私が、現役メンバー引退後のミッションとしてこれらの問題を解決するために始動させました。
今は抱える問題解決が主な開発目的ですが、将来的にはこのBotのおかげで取り掛かれることを開発していきたいと考えています。

現状の開発状況はこちら↓
コマンドにより会計担当の一部業務をこなす機能、レギュレーション検索ができるRAG機能が実装済みです。
また，特定キーワード（〇〇班等）に反応し、設定したメンバーにメンションが飛ぶ機能も搭載しています。


## 主な機能
- **会計管理システム (`/accounting`)**
  - **レシート画像認識による支出入力**: OpenAIの画像認識モデルを用いてレシート情報抽出をし、支出をスプレッドシートに記入します。
  - **手動支出入力**: レシートや明細の内容を手動で入力し、支出をスプレッドシートに記入します。
  - **部費状況確認**: スプレッドシートを参照し、各メンバーの支払い状況をSlackで照会できます
  - **その他収入入力**: OBからの寄付等を手動で入力し、収入をスプレッドシートに記入します。
- **RAG ドキュメント検索**
  - 指定チャンネル内でのメンションに対し、Botが学生フォーミュラのレギュレーションに関する質問に回答します。

## 🛠️ 技術スタック
- **Language**: Python 3.12+
- **Infrastructure**: Google Cloud Run (kf-slack-application)
- **Database**: Google Sheets (API 連携)
- **AI**: OpenAI API

## 🔧 環境変数 (Secret / Configuration)
Cloud Run の環境変数として以下の設定が必要です。

### 🔑 認証・APIキー
- `SLACK_BOT_TOKEN`: Slack Botトークン
- `SLACK_SIGNING_SECRET`: Slack署名シークレット
- `OPENAI_API_KEY`: OpenAI APIキー
- `PINECONE_API_KEY`: Pinecone APIキー

### 📊 スプレッドシート連携
- `ACCOUNTING_SHEET_ID`: **スプレッドシートの個別 ID**
  - ※ スプレッドシートの URL `https://docs.google.com/spreadsheets/d/(〇〇)/edit` に含まれる英数字の文字列です。シートの名前ではないので注意してください。

### 💬 Slack チャンネル連携
- `RAG_CHANNEL_ID`, `ACCOUNTING_CHANNEL_ID`: **動作させたいチャンネルの ID**
  - ※ Bot を反応させたいチャンネルごとに、それぞれの ID を個別に設定する必要があります。
  - ※ チャンネル ID は、Slack 上で「チャンネル名を右クリック ＞ チャンネル詳細を表示 ＞ 最下部」から確認できます。

### 🧠 検索インデックス (RAG)
- `PINECONE_INDEX_NAME`: Pinecone で作成したインデックス（Index）の名前
