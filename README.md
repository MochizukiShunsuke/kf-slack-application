#### 会計機能

・コマンドorメッセージショートカットにより会計担当の収支入力作業をを行う機能
・コマンドにより各部員の部費支払い状況を照会できる機能

#### レギュレーション検索機能

・コマンドorメンションでレギュレーション検索ができるRAG機能
	コマンドトリガー：誰にも知られずにレギュレーションに個人で非公開に質問できる。
	メンショントリガー：チーム全体の前で質問でき、質問内容は共有される。
					　スレッドで会話をすることで文脈を使ったAI Chatが可能

#### メンション機能

・特定キーワード（〇〇班等）に反応し、設定したメンバーにメンションが飛ぶ機能

#### 近況活動報告作成催促機能

・毎月15日と20日に25日提出締め切りの近況活動報告書の原稿の作成を担当者にリマインドメッセージを送る機能

#### 共用PC予約機能

該当チャンネルで行うPC利用宣言のメッセージに予約リアクションを押すことでそのPC利用が完了後予約者に通知が飛ぶ機能
